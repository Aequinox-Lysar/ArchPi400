# Aeqinox Lysar - Systemübersicht

## Hardware
- Raspberry Pi 400 (4GB)
- Micro SD-Karte: 64 GB Samsung EVO
- SanDisk Ultra Fit USB 3.2 Flash-Laufwerk 128 GB
- Tastatur integriert, externs Display via HDMI
- Kein GUI, TTY-only Setup

---

## Betriebssystem
- Arch Linux Arm
- Ziel : portables, lernorientiertes Labor ("Mein Labor der wilden Ideen")

---

## Grundidee
Ich möchte ein minimalistisches, vollständiges System zum Lernen und Experimientieren haben.
Fokus auf:
- manuelles Kompillieren ( LFS *hoffentlich* )
- Bash-Scripting
- Python
- Dokumentation in Markdown mit gleichzeitigem Neovim Training
- tmux als Arbeitsoberfläche
