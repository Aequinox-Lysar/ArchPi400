# Bugfix: Konfigurationsdateien im Repo sammeln

**Datum:** 28.10.2025

## Problem
Konfigurationsdateien sollen im Repository gesammelt werden aber dennoch im System funktionieren.

## Ursache
Ich dachte mir es wäre doch cool wenn ich, falls ich meinen ArchPi400 mal reproduzieren muss,das ich dann alle Kofigurationsdateien direkt zur hand habe.
## Lösung
Mein aktueller Lösungsansatz ist das ich meine Konfigurationsdateien innerhalb meines Repositories im Ordner `dotfiles` ablege, und mittels Softlinks an den Positionen wo das System sie benötigt verlinke. So bleibt die Funktionalität erhalten und die Dateien kommen trotzdem ins Repository.

**Befehle die ich verwendet habe:**

```bash
# Datei in den dotfiles Ordner kopieren.
mv ~/.bashrc "<Pfad zum Zielordner>"

# Symlink erzeugen.
ln -s "<Pfad zur .bashrc im Repo>" ~/.bashrc

```

## Erkenntnisse
Hier habe ich das Konzept der Dateilinks das erste mal praktisch ausprobiert und es hat mein Problem gelöst.
